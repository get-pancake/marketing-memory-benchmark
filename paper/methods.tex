\section{Comparison design}
\label{sec:methods}
We isolate evidence selection on a common file-based backend. All adapters receive the same verified events, easy seller/account entity scope, time/access boundary and catalog. Thus the experiment does not test whether introducing typed facts is better than unstructured prose: every control already has typed facts and provenance. It tests how to select them for a bounded reader input.

The hybrid retriever combines BM25 ($k_1=1.2$, $b=0.75$) with cosine similarity of normalized Qwen3-Embedding-0.6B vectors~\citep{p250605176}. Reciprocal-rank fusion uses a constant of 60 and equal contributions. The query includes the account, objective, and prerequisite vocabulary of every objective- and budget-compatible template for \emph{all} methods. The specialized method is therefore not alone in receiving the domain vocabulary. Ties are broken by immutable source identifier.

\begin{description}
\item[Generic hybrid.] Fused relevance ranking with the common task contract.
\item[Prompt hybrid.] The same ranking plus a GTM checklist covering role/geography fit, signal/state, pain, proof and approved policy. This is the primary control.
\item[Facet hybrid.] The same prompt and ranking, traversing distinct entity/relation/authority groups round-robin before taking further members of a group. This control tests domain-neutral evidence diversity.
\item[Catalog coverage.] Required groups for templates matching the objective and resource allowance come first. Within each priority tier, fused ranking determines the initial group order; subsequent rounds preserve that order. Selection never reads gold labels or selects required values from answers.
\item[Full context.] Every eligible event, with the same checklist. This is a larger-input reference whose tokens and latency are reported separately.
\item[History ablation.] Catalog coverage with deterministic supersession removal disabled. Replacement links and times remain visible to the reader; permissions and time cutoffs remain enforced. This isolates the value of resolving replacements before retrieval in this implementation.
\end{description}

For bounded adapters, events are considered in ranking order and admitted only if the complete serialized prompt remains within the common token cap. Later smaller events can still fit after a longer event is rejected. The cap includes system instructions, query, catalog and evidence. The generic prompt is shorter, so it can admit more evidence within the same total allowance. Selected events are finally presented in immutable-ID order under a common rule. Selection still changes positions and short source labels, so content availability and position effects are not independently identified. Full context fails explicitly above its safety cap; it is never silently truncated.

All methods share one planned reader decision, decoding settings, output allowance and binding grammar. No automatic retries, additional verification model or answer repair favor one adapter. The validator and mock execution follow the same rules for every output. Source selection can make a contract impossible to answer correctly, but withholding on an answerable complete record remains an error: this measures the end-to-end consequence of missing evidence rather than rewarding retrieval omissions.

Within each main block, identical serialized requests reuse the first actual response, including incorrect or malformed responses. The complete request body preserves schema field order and decoding settings; origins and raw outputs are retained. Seven repeated-input groups in the independently executed pilot returned identical raw outputs. This supports the resource-saving design without proving universal numerical repeatability. Logical comparisons and physical generation requests are reported separately. Method-level token/time totals charge the observed origin call to each identical request; physical totals count it once. No development generation output is imported into the main blocks.

An exact SQLite policy reference also receives the full verified record. It evaluates the declared joins and returns one witness per required slot, then passes through the same Python scorer and mock execution. This reference establishes the capability of an explicit rule evaluator on a rule-defined task. It is not a learned agent, an ingestion benchmark or evidence of commercial optimality.

The local implementation records exact weight hashes, upstream revisions, runtime build, prompts, source selections, model usage and terminal status. The token count from the runtime's chat template/tokenizer is checked against returned usage for each call. Embedding cache receipts retain their original computation times, so a method does not receive a free-ingestion advantage from running after another method. Supplementary accounting deduplicates shared embedding origins across blocks and estimates each method's component cost by charging its unique origins, non-embedding retrieval overhead and logical generation work. These are estimates from shared execution, not measured isolated deployments. Embedding time is already included in observed retrieval time and is not added twice. Times are elapsed wall-clock measurements on the CPU server, not accumulated process CPU time. Local API charges are zero; elapsed time, hardware rental value and energy are different quantities, and the latter two are not measured.

\section{Data and evaluation}
\label{sec:evaluation}
The dataset contains original programmatically authored fictional company worlds. The research assistant authored the generator and text templates; instantiation uses no separate narrative-generation model calls. There are no customer records or human annotations. Construction rules specify acceptable alternatives; separately implemented Python and SQLite evaluators verify the time/access and contract logic. This is software cross-validation by the same research process, not independent authorship or expert validation.

Each world has eight queries: initial eligibility; weak feedback and a proposed, unapproved policy; approved policy revision; account requalification; a later-observed backdated correction; restricted proof access; a changed objective; and conflicting approved policy. Four queries permit a supported action and four require withholding. Always withholding therefore receives 50\% decision accuracy. The late-correction case holds the earlier valid-time cutoff while advancing knowledge time, distinguishing the two temporal axes. The access and objective interventions query earlier snapshots under changed permissions or purpose; the eight conditions are not one uninterrupted chronological sequence.

Pilot worlds use hiring and migration contracts. The main set contains 12 worlds and 96 queries, with four worlds per held-out renewal, partner and compliance family. These add different relation combinations. Worlds vary names, buyer roles, geographies, date gaps, template-ID permutations, resource limits, distractors and duplicate evidence. Queries from a world remain together. All families share the same generator and common policy slots; family holdout is compositional generalization within this generator, not an independently sourced domain transfer test. Structural checks inspect all public contract definitions, but no main-model outcome is used for tuning.

The primary block compares all six methods at 1,024 total input tokens, with 576 planned logical attempts. An exploratory block compares prompt hybrid and catalog coverage at 1,536 tokens on the same queries, adding 192 planned attempts. Full context is separately costed. Twelve worlds follow a prospective precision rule using a paired-world SD floor of 0.20, because two pilot worlds are insufficient for stable variance estimation, and an approximate interval half-width target of 0.15. This heuristic does not guarantee achieved precision. The exact rule, pilot outcomes, code/data hashes and ordering seeds were recorded before main inference.

The primary outcome is a \emph{correct supported decision}: a completely supported applicable recommendation, or correct withholding when no alternative is supported. Every planned attempt remains in its denominator; failed, malformed, truncated and missing attempts cannot disappear. Separately reported dimensions include applicable template choice without complete citations, positive-case supported coverage, available support in retrieved evidence, inappropriate withholding, recommendations on negative cases, schema errors, mock execution completion and computation. Free-text reasons for withholding are retained but are not scored for semantic correctness; a correct negative decision does not establish a correct explanation.

The primary contrast is catalog coverage minus prompt hybrid. Facet diversity, the generic prompt, full context and history handling are explanatory comparisons. Queries and methods are paired within company worlds. Uncertainty uses world-level differences and a bootstrap stratified by held-out family, preserving all repeated queries from a sampled world together. Confidence intervals describe variation within the fictional generator and tested model, not commercial-population uncertainty. A small or degenerate interval cannot certify external validity, and nonsignificance does not establish equivalence. The saved protocol specifies sample selection and all settings before main execution.

Transition diagnostics report the fraction of worlds correct both before and after stable feedback or an evidence/policy change, as well as the corresponding conditional rate among correct earlier decisions. They do not manufacture new independent samples from adjacent queries or prove dependency-aware incremental recomputation. Raw output and analysis artifacts permit recomputation of every reported count. The prospective freeze was recorded in the working repository before inference; it was not an external preregistration.
