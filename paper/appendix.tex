\section{Reproduction and experimental boundary}
The companion separates four commands: offline contract checks, actual model inference, analysis of saved outputs, and manuscript compilation. The first requires Python 3.12; figure generation adds pinned NumPy and Matplotlib dependencies. Fresh inference requires separately downloaded hash-checked weights, the pinned \texttt{llama.cpp} source, compatible CPU instructions and approximately 32 GiB of memory. The main weights occupy about 19.2 GB including the embedding model. Model files, third-party papers and private product material are excluded from the companion. Preparing the package does not itself publish it or submit the report to a venue.

The generation checkpoint is Qwen3-30B-A3B-Instruct-2507, with approximately 30.5 billion total and 3.3 billion active parameters, in Q4\_K\_M quantization. We use the checkpoint's non-thinking mode rather than a generated reasoning trace. The embedding checkpoint is Qwen3-Embedding-0.6B in Q8\_0, using its final/EOS representation, 1,024 dimensions and normalized cosine similarity~\citep{p250509388,p250605176}. Quantization and deployment choices are resource constraints, not model-compression contributions. Complete upstream revisions, SHA-256 hashes, server flags and binary hashes are saved with the runs.

The reader serves a 16,384-token context with one slot, four CPU threads and prompt caching disabled; the embedding service uses a separate loopback endpoint. Each planned decision has temperature 0, seed 20261022 and at most 280 output tokens. The request body, schema field order and all returned usage are retained. Other sampler defaults are recorded from the running server, rather than inferred from an external API's defaults. A fixed seed is not a guarantee of cross-hardware bitwise determinism.

The primary block orders its 576 attempts with seed 20261022; the secondary block orders 192 attempts with seed 20261023. There is no generation-response reuse between blocks. The secondary block can reuse the common embedding index, retaining computation origins. A transport failure stops execution for repair. Resumption preserves completed and failed attempts, marks issued attempts without terminal records as interrupted failures, and starts only previously unissued work. An exclusive lock prevents two processes from executing one run concurrently. Unknown usage from an interruption remains unknown rather than being assigned zero cost.

The provenance audit reconstructs prompts from the original eligible facts and public catalog, checks source aliases and output grammar, and compares exact serialized request settings. Offline mutation checks reject rehashed forged facts, altered decoding settings and duplicate physical-call records. These checks support artifact consistency; they are neither independent expert validation of the task nor a formal security proof.

The primary interval uses 10,000 bootstrap draws with seed 7201, resampling four worlds with replacement within each of the three held-out families. The effect is the average of paired world differences. Other comparisons and the input-budget sensitivity explain behavior; they are not a multiplicity-adjusted family of superiority tests. The public freeze files record this analysis specification, the 13 source-file hashes and both dataset hashes before main inference.

A descriptive error-localization report was added after the freeze but before main quality outcomes were inspected. It crosses complete-witness availability with positive decision correctness and preserves the original scores and denominators. Exclusive categories distinguish execution/output failures, missing retrieved support, withholding despite available support, inapplicable choices, and invalid bindings. All paired disagreements are retained; illustrative trace pointers select the first lexicographic case within each category. These summaries support inspection, not causal mediation estimates or additional confirmatory tests.

An input-only audit added after the freeze, before main outcome inspection, constructs one complete minimal-slot witness for each of the 48 answerable queries. All fit 1,024 tokens: the largest requires 882 with the generic prompt and 951 with the checklist. This establishes representational capacity, not retrieval or reader success, token-optimal selection or a new evaluated method. Messages, rendered prompts, tokenizer receipts and hashes are retained in \path{analysis/diagnostics/input-capacity.json}. No generation call or experimental outcome enters this check.

A corresponding pre-results output audit constructs one correct decision per query from the public contract. All 96 fit the 280-token allowance: compact JSON requires at most 127 tokens and two-space indentation at most 170, including one end token. This does not establish successful generation or correct explanations. Exact strings, tokenizer receipts and offline checks are in \path{analysis/diagnostics/output-capacity.json}; the diagnostic reads neither labels nor experimental responses.

\section{Fixture semantics and development disclosure}
The main generator seed is 2026102202; the development seed is 2026102201. The main families are renewal, partner and compliance. Their task-specific relations respectively connect customer state and usage trend; partner status and channel fit; or certification and an observed compliance signal to an offering pain and proof. These literal requirements are public catalog definitions. Their presence is not a hidden reward function or a learned estimate of commercial utility.

Every world has four answerable and four unanswerable queries. Approved policy revision initially creates a targeting mismatch; a later account observation restores fit. An observation learned still later corrects an earlier signal, even when the valid-time cutoff is held fixed. Restricted proof is unavailable to a requester lacking its required scope. An unrelated approved role without a supersession link creates a genuine conflict. Weak feedback and an unapproved policy proposal do not themselves change approved strategy. The positive changed-objective case requests only a qualification audit. Labels and condition names remain outside reader messages.

The two main research alternatives share prerequisites. The three-step variant researches the account, verifies prerequisites and prepares a report; the two-step variant omits the first step. A world-specific allowance of two or three artificial units controls their eligibility. A separate procurement alternative requires an executive-only source. The main histories contain 28--56 events each. There are three worlds at each distractor count of 12, 20, 28 and 36. Zero, one or two duplicate pairs occur in three, five and four worlds respectively, sampled independently of family. Duplicate records carry the same value and do not create additional facts. These realized counts are saved in the dataset's \texttt{design-summary.json}.

Development failures are retained in the companion's tuning record and raw ledgers. The first compact citation interface proved unreliable with the smaller readers; a schema-serialization defect was also corrected before the main freeze. Subsequent common-interface changes replaced long identifiers with exact source labels, then required a prerequisite table and clarified that a missing prerequisite blocks only alternatives that require it. No missing source is filled by the evaluator. The final 48-call pilot established that even full context could fail despite containing a complete witness. Main evaluation therefore measures both selection and utilization, rather than assuming that retrieval availability implies a correct recommendation.

For the final pilot, a diagnostic taxonomy correction changed repeated source bindings from a flat-citation shape error to a per-slot semantic error. All 48 primary correctness outcomes remained unchanged. The original records and the audit are preserved. This correction does not remove wrong bindings, repair model outputs or alter the main task after observing its results. The final frozen materializer deduplicates citation sets while preserving every original prerequisite binding for validation.
