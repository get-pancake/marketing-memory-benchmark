\section{Protocol, implementation and reproduction details}
\label{sec:reproduce}
The main freeze is \texttt{experiments/integrated/main-freeze-v1.json}, committed at \texttt{61c57c6}. Seed 2026102302 produces 33 worlds (11 per family) and 264 cases. The input hash starts \texttt{449072b7255f}. Pilot seed 2026102231 produces four worlds and 32 cases. The pilot's maximum paired world SD was 0.2165, selecting 33 worlds through the prespecified precision rule. Earlier test families informed development; this is a fresh-world evaluation within a known generator, not a claim of wholly unseen task design. Each case is executed once per context/provider, with native structured output and no answer sampling. Software source snapshots and complete hashes accompany the run.

GBrain's full pin is \texttt{531b3b1ab66c88f192abb51338028c44b80fbf21}. The external development corpus comes from \texttt{garrytan/gbrain-evals} at \texttt{6999ebc9da0ac784ac05995b586d22293544e924}; per-file URLs and hashes are retained. These repositories and the original adapters have MIT licensing; original generated fixtures/documentation have CC BY 4.0 scope. Third-party paper PDFs, copied abstracts, credentials, production code and private planning history are excluded from the public package. No GBrain hosted configuration or official Karpathy implementation is claimed.

The common event filter is deliberately shared. It performs observed/valid-time gating, scope checks and explicit supersession. ``History handling'' in this study therefore means selecting from a maintained current view; no independent advantage in ingestion, belief revision, authorization or update latency is estimated. Source aliases are generated from the supplied packet, while all permissible action IDs remain in the public schema. The JSON schema fixes serialization, not the correct decision. No-context contains no source aliases and cannot invent evidence.

\paragraph{Failed development attempts.}
The initial provider pilot was stopped after 132 issued requests: 124 completed and eight Claude responses had malformed JSON. Its remaining 316 plans were not issued. The amended native-schema pilot completed 448 requests. Both attempts remain, with no successful replacement inserted into the failed ledger. Schema-integration errors, local embedding-path failures and synchronous wiki failures are also preserved. Reported usage excludes unknown billing when a timeout prevented a usage receipt; unknown is not zero. During the main run, a runtime reconnection stopped the process after eight response/result files were saved but before their terminal ledger entries. Those exact verified files were recovered, and only the remaining 624 unissued requests were resumed. No generation was repeated; the before/after journals and recovery receipt are retained.

\paragraph{Reproduction scopes.}
The inexpensive smoke tests use no provider calls. The saved-output path rebuilds data, every context packet, raw-response scores, statistical summaries and vector figures, then compiles both PDFs. A clean extracted directory and isolated, hash-pinned Python environment test this path; the hardware and system TeX are shared with the original run. Fresh inference is a separately priced command requiring current provider access; it may not be byte-identical. Fresh native GBrain search requires the pinned upstream/Bun dependencies. Fresh embeddings are optional when using the released actual vector snapshot. Commands and requirements appear in the companion README.

\paragraph{Historical evidence.}
The previous local Qwen3-30B-A3B study and exploratory GBrain extension are archived rather than pooled into the new sample. They used different readers, budgets and data. They motivated competent reader checks, a full-context reference, wider-budget sweeps and generic coverage controls. Exact historical PDFs, attempts, source hashes and reproducibility receipts remain under \texttt{release/history/} and the original experiment directories. The new paired effects come exclusively from the frozen integrated main study.
