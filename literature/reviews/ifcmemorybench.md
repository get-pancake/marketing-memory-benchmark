# IFCMemoryBench — full-text critical review

Reviewed 22 October 2026 UTC. Primary source: arXiv:2607.26072v1, *IFCMemoryBench: Evaluating Long-Term Memory of LLM-Based Agents in BIM Information Retrieval*, Changyu Du, Alexander Vosseler, Filippo Mazza and André Borrmann. The paper identifies the KDD 2026 Workshop on Evaluation and Trustworthiness of Agentic AI. Read the main study, discussion, references and evaluation/prompt appendices; the large pipeline figure is available in the cached PDF. Reported results are not reproduced here.

This is very close methodological prior work: domain memory is evaluated through use alongside live structured tools, with ingestion, retrieval and utilization separated. The benchmark contains 143 tasks, 19 projects, 23 IFC models and 4,016 prior sessions. Missing information is synthesized or sourced externally, inserted into user messages, and conversations replayed against IFC tools. Authors report human review of construction. A single expert relabels 40 outputs: answer agreement 38/40, memory agreement 40/40 (§3.3). That supports the particular rubric on a limited sample; it is not a broad guarantee of all generated labels or all judge/model comparisons.

The shared probe agent uses Grok-4.3; comparison methods instantiate Mem0, Graphiti, uncited Markdown and cited Markdown. Model defaults and different embedders remain part of the configurations. Table 2 reports answer accuracy 32.4% for Mem0 and 21.0% for Graphiti in the user-plus-final-answer setting. Table 3's ingestion-scope intervention is crucial: durable facts are deliberately seeded only in user turns, so user-only filtering is near-oracle and its advantage is partly constructed. Full-context user-only accuracy is 83.2%, dropping to 44.1% with final answers (§4.5). These are different information/noise scopes, not evidence that long context universally replaces memory.

The domain-customization result is explicitly mixed (§4.6/Figure 3): a schema/template improves cited Markdown answer accuracy from 24.5% to 35.7%, while an extraction instruction reduces Mem0 from 32.4% to 28.2%. It directly falsifies a blanket assumption that domain instructions always help. A stronger probe changes method ranking and issues more searches (§4.7); attributing this gain solely to memory would be wrong. The paper accounts for ingestion and probe tokens and highlights amortization, which our study should preserve.

Critical limits: task-level Wilson intervals ignore potential clustering within the 19 projects; paired task analysis is preferable to independent-binomial comparison but still does not automatically solve project dependence. A common judge/model family may favor some output forms even when used uniformly, so equal exposure is not proof of absence of ranking bias. The construction description calls gold answers generated and human-validated, while later prose calls them human-authored; retain the more explicit pipeline provenance. Full turns are tested only for file memory due to budget. Exact dependency versions, source-code availability and dataset redistribution terms require artifact checks before reuse; an arXiv PDF is not a dataset license.

Reuse decision: adopt the common-agent control, cost accounting, source traceability and decomposition, not the IFC task/data. GTM specialization is not novel merely because IFC is another domain. Our narrower contrast must isolate a mechanism under common facts and budgets and explicitly retain full context. The paper motivates testing a generic coverage-aware control, since fragmented evidence rather than absence of an ontology can explain failure.
